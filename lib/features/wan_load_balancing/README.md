# WAN load balancing

واجهة Fusion Reactor مرتبطة بـ Riverpod وMikroTik REST API في RouterOS v7.
تقرأ الواجهات الفعلية، تتحقق من تعارض PCC، وتطبّق جداول التوجيه وقواعد mangle وNAT بعد موافقة صريحة وتأكيد النسخة الاحتياطية وخطة التراجع.

لا تستبدل قواعد PCC غير المُدارة تلقائيًا، ولا تنشئ مسارات failover احتياطية. راجع إعدادات البوابات وNAT والتوجيه قبل التنفيذ على شبكة إنتاج.
