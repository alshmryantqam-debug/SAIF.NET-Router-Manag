# NOVA — منصة موحّدة لإدارة شبكات MikroTik

NOVA هو التطبيق الرئيسي الواحد للمشروع. الشاشات والأدوات الموجودة في `lib/screens/` و`lib/features/` هي وحدات داخل التطبيق نفسه وليست تطبيقات مستقلة.

## مبادئ الدمج

- نقطة تشغيل واحدة: `lib/main.dart`.
- هوية موحدة: NOVA.
- التنقل المركزي عبر `lib/app_router.dart`.
- غلاف تنقل رئيسي واحد عبر `lib/screens/main_shell.dart`.
- مركز أدوات واحد يجمع الميزات حسب المجال في `lib/screens/tools_screen.dart`.
- الاحتفاظ بملفات الميزات والخدمات والنماذج والاختبارات؛ لا تُحذف ميزة لمجرد أنها موجودة في مجلد مستقل.
- حذف التكرار من قوائم الأدوات بدل إخفاء الميزات الأصلية أو إنشاء نسخ مكررة منها.

## المجالات الموجودة

- الاتصال وإدارة أجهزة الراوتر.
- لوحة القيادة ومراقبة حركة المرور والواجهات.
- PPPoE وHotspot والمشتركون والقسائم.
- الجدار الناري والطرفية وهندسة الشبكة.
- تشخيص الصحة والتنبيهات.
- موازنة خطوط WAN وPCC.
- الرادار والسونار ومراقبة الوصلات.
- الذكاء الاصطناعي والأتمتة ونواة NOVA.
- النسخ الاحتياطي والإعدادات والفوترة والأدوار.

## ملاحظات الجودة

وجود شاشة أو مسار تنقل لا يثبت وحده أن كل عملية متصلة فعلياً بالراوتر. يجب اختبار كل ميزة على حدة، والتأكد من وجود خدمة حقيقية خلفها، وعدم عرض نجاح وهمي. عمليات تغيير إعدادات الراوتر تبقى محمية بمعاينة وتأكيد واضحين وآلية تراجع حيثما كانت مدعومة.
