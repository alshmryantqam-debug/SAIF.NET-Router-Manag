# SAIF.NET Router Manager

منصة Android عربية لإدارة ومراقبة شبكات MikroTik، بواجهة RTL داكنة بنفسجية. المشروع في مرحلة تجريبية؛ هذه الصفحة تميّز بين الميزات المنفذة فعلاً والميزات التي ما زالت تحتاج تكاملاً واختبارات.

## الموجود في هذا الفرع

- **لوحة قيادة**: قراءات موارد الجهاز المتاحة، مع عرض القيم غير المتوفرة على أنها غير معروفة بدلاً من اختلاق أرقام.
- **مركز مراقبة الشبكة**: الواجهات، جلسات HotSpot وPPPoE النشطة، عقود DHCP، Simple Queues، عناوين IP، المسارات، قواعد Firewall وسجل النظام.
- **مراقبة WAN**: قراءة قائمة الواجهات التي ينتمي إليها كل خط WAN، وعينة RX/TX من RouterOS `monitor-traffic`، وتنبيهات إرشادية عند توقف واجهة WAN أو ارتفاع CPU/الذاكرة/الحرارة.
- **REST وBinary API**: مسارات قراءة موحدة، ومعالجة ردود Binary API المتعددة، وتنظيف الطلبات عند انقطاع الاتصال.
- **أمان TLS**: لا يتم قبول الشهادات غير الصالحة تلقائياً. يلزم إعداد شهادة موثوقة؛ الاتصال غير المشفّر يتطلب تحذيراً وموافقة صريحة في الواجهة.
- **خزنة نسخ محلية مشفّرة**: تشفير AES-256-GCM للنص الذي يقدمه المستخدم، ومفتاح محلي في التخزين الآمن، وفحص سلامة النسخة قبل فكها.
- **معاينة تغييرات Safe Apply**: نموذج للتحقق من خطة منظمة وقائمة موارد مسموح بها، مع شرط النسخة الاحتياطية والموافقة وإخفاء القيم السرية.
- **مقارنة الإعدادات**: تنقيح الحقول السرية، بصمة SHA-256 للنسخة المنقحة، وعرض الفروقات بين نسختين.
- **بناء Android**: GitHub Actions يشغّل الاختبارات، وينشئ ملفات Android على بيئة البناء عند الحاجة، ثم يبني APK تجريبياً ويرفعه كـ artifact.

## حدود مهمة حالياً

- لا يجرى أي اتصال فعلي براوتر الإنتاج أثناء اختبارات GitHub Actions.
- خزنة النسخ لا تسحب تصديراً من الراوتر تلقائياً؛ الصق تصدير RouterOS الذي حصلت عليه بنفسك.
- فك النسخة الاحتياطية للعرض لا يستعيد الإعدادات إلى الراوتر.
- Safe Apply ما زال معاينة/تحققاً فقط؛ لا يوجد منفّذ تغييرات إنتاجي أو rollback آلي مكتمل.
- تنبيهات WAN تعتمد على وجود واجهات ضمن قائمة RouterOS المسماة `WAN`. إذا لم تكن القائمة معدّة أو لم تتوفر الصلاحيات، يعرض التطبيق أن الحالة غير مؤكدة.
- معدلات RX/TX هي عينة واجهة لحظية وليست اختبار سرعة إنترنت كاملاً.
- يلزم اختبار فعلي على CHR مع RouterOS v6 وv7، ثم تجربة هاتف Android، قبل اعتماد إصدار إنتاجي.
- مفتاح النسخ المشفّرة محفوظ على الجهاز؛ فقدان بيانات التطبيق أو المفتاح قد يجعل النسخ غير قابلة للاسترداد. آلية استرداد مشفّرة مستقلة ما زالت مطلوبة.

## بناء APK تجريبي

1. افتح تبويب **Actions** في GitHub.
2. اختر **SAIF.NET Android APK**.
3. اضغط **Run workflow** وحدد فرع `feature/saif-integrated-platform`.
4. انتظر نجاح الاختبارات وبناء APK.
5. من نتيجة التشغيل، نزّل artifact باسم `saif-net-router-manager-debug-apk`.

الملف الناتج **Debug APK للاختبار** وليس إصداراً إنتاجياً موقّعاً. لا تثبّت ملفاً من تشغيل فاشل. الإصدار الإنتاجي يحتاج إلى عملية توقيع آمنة ومراجعة أذونات التطبيق.
