# Architecture
- Presentation: الشاشات والـ widgets الحالية، ثم features تدريجياً.
- State: providers.
- Data/domain: نماذج ومحوّلات ومستودعات.
- Infrastructure: REST وBinary API والتخزين الآمن.

قواعد النقل: لا حذف للشاشات الحالية، لا نماذج مكررة، انقل مجالاً واحداً في كل مرة واختبره. لوحة المراقبة قراءة فقط افتراضياً.
