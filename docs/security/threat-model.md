# Threat model
الأصول: بيانات اعتماد الراوتر وبيانات المشتركين ونسخ الإعدادات.

الضوابط: أقل صلاحية ممكنة، تخزين آمن، TLS، تنقيح السجلات، عدم كشف واجهة الإدارة للإنترنت، تأكيد العمليات الكتابية، وتسجيل تدقيق.

المخاطر المتبقية: جهاز Android مخترق، شهادات غير موثوقة، وتصدير ملفات إعدادات تحتوي أسراراً.
